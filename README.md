## Featured Projects

### Book E-Commerce Backend API

A modular RESTful backend for an online bookstore with six core areas: users, books, categories, reviews, carts, and orders.

- JWT authentication with HTTP-only cookies.
- MVC-style structure using routers, controllers, models, and middleware.
- MongoDB and Mongoose data modeling.
- Stripe Checkout and webhook handling.
- Cloudinary media uploads and centralized error handling.

[View repository](https://github.com/Ahmed-Abdulhafez/Book-E-Commerce-BackEnd)

### Clothing Store Backend API

An e-commerce backend for products, categories, users, reviews, carts, orders, and payment workflows.

- JWT authentication and authorization.
- MongoDB and Mongoose integration.
- Stripe payment processing.
- Cloudinary media management.
- CORS configuration and modular route organization.

[View repository](https://github.com/Ahmed-Abdulhafez/Clothing-Store-Backend)
